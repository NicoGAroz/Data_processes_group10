# Data_processes_group10

Preoperative ICU Admission Prediction
This repository contains the data preprocessing and machine learning training pipeline for predicting whether a patient will require postoperative transfer to the Intensive Care Unit (ICU). By predicting ICU admission before surgery occurs, this tool aims to assist clinicians in preoperative planning, risk assessment, and hospital resource allocation.

Dataset
The models are trained on the EPIC MOVER dataset, which consists of clinical data extracted from hospital Electronic Health Records (EHR). The dataset contains structured, tabular preoperative patient information.
